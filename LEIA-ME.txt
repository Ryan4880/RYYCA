LOVE.PROJECT — PRESENTE DIGITAL
================================

REQUISITOS
- Um navegador moderno.
- VS Code (opcional, mas recomendado).
- Live Server (opcional). Não há dependências npm.

COMO ABRIR
1. Extraia a pasta love-project.
2. No VS Code, use File > Open Folder e selecione a pasta.
3. Abra index.html no navegador ou clique com o botão direito nele e escolha
   "Open with Live Server", caso tenha essa extensão.

PERSONALIZAÇÃO
Abra script.js e edite o objeto CONFIG no começo do arquivo:

- nomeDela: nome ou apelido que você usa com ela.
- seuNome: seu nome/apelido.
- dataInicio: data do início do relacionamento no formato AAAA-MM-DD.
  Exemplo: "2024-06-15". Deixe "" para não ativar o contador.
- motivos: personalize os dez motivos com coisas reais de vocês.
- memorias: personalize os títulos e textos dos commits.

IMPORTANTE
O projeto usa HTML, CSS e JavaScript puro. A referência a React é temática;
não é necessário instalar React para executar este presente.

COMO PUBLICAR E ENVIAR
Você pode hospedar a pasta em um serviço de hospedagem estática, como GitHub
Pages ou Netlify, e enviar o endereço gerado pelo WhatsApp. Para manter a
surpresa, teste o link em uma janela anônima e também no celular antes de
enviar.

ESTRUTURA
index.html  -> estrutura e conteúdo da página
style.css   -> visual, layout responsivo e animações
script.js   -> comandos do terminal e personalização
LEIA-ME.txt -> estas instruções
